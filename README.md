# sales-performance-power-bi-dashboard

Developed an interactive Power BI dashboard to analyze sales, profit, customer, and order performance across different years and regions. The dashboard includes year-over-year growth analysis, customer analysis, and product performance analysis.

## Tools Used

- Power BI
- DAX
- Power Query
- Data cleaning
- Data visualisation
  
## Steps
1.Imported the sales dataset into Power BI and reviewed the data.
 
2.Cleaned and transformed data using Power Query 

3.Created DAX measures and calculated columns 

4.Created relationships and a date table 

5.Built interactive dashboards using KPIs, slicers, and visualizations

6.Added navigation buttons to move between dashboard pages

7.Analyzed year-over-year sales and profit performance
